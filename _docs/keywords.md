# Keywords y clusters del blog

Investigación del 19/11/2026 para el blog de CMP Solutions, en español de Argentina.

Esta carpeta empieza con `_`, así que GitHub Pages no la publica: queda solo en el repo.

## Cómo leer los volúmenes

No hay herramienta paga de keywords conectada (DataForSEO, Ahrefs, Semrush). El volumen es una **estimación relativa** a partir de cuánta cobertura tiene cada tema en medios y portales, cuántos resultados pelean por él y cuánto se repite en notas de los últimos meses. No son números de búsquedas.

| Nivel | Qué quiere decir |
|---|---|
| Muy alto | Tema que todos los medios grandes cubren cada mes (ej. créditos hipotecarios). Muy difícil de rankear para un sitio nuevo. |
| Alto | Búsqueda frecuente y estable, con portales inmobiliarios en la primera página. |
| Medio | Búsqueda real con menos competencia; un sitio nuevo puede entrar con una buena nota. |
| Bajo | Pocas búsquedas, pero intención muy precisa. Para CMP, las B2B de este nivel valen más que las de volumen alto. |

**Para tener números reales:** Google Keyword Planner (gratis con una cuenta de Google Ads, sin pautar) y, a los 2 o 3 meses de publicar, el informe de Rendimiento de Search Console. Recomiendo revisar esta tabla con esos datos en febrero de 2027.

## La estrategia en una línea

El cliente de CMP es quien **vende** pozo, así que el blog le habla primero a él (decisión de Pedro del 19/11/2026). El cluster D (comercializar pozo) es la prioridad: tiene poco volumen, pero trae a inmobiliarios, comercializadoras y desarrolladoras. Los clusters A, B y C responden preguntas del **comprador** y se escriben como material para que el broker se lo mande a sus clientes: tienen un botón para compartir por WhatsApp, y el cliente ve la nota sin los recuadros para inmobiliarios. Esas notas traen volumen y citas de las IA, que le dan autoridad al sitio, y le dan al broker algo útil de CMP.

Proporción: 10 de cada 15 notas para vendedores (ver [plan-editorial.md](plan-editorial.md)).

## Intención de búsqueda

- **Informacional:** quiere entender algo (qué es, cómo funciona, riesgos).
- **Comparativa:** está decidiendo entre dos caminos (pozo o usado, hipotecario o cuotas).
- **Transaccional:** quiere hacer algo ya (simular, pedir, contratar).
- **B2B:** es inmobiliario, comercializador o desarrollador y busca cómo trabajar mejor.
